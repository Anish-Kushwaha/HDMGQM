# HMGQM Theory

Official web presentation of **Hyper-Dense Magneto-Gravitational Quantum Matter (HMGQM)**.

## Website
The static website is intentionally kept in the **repository root** for GitHub Pages:

- `index.html` — Theory overview
- `physics.html` — Physics & Mathematics
- `predictions.html` — Predictions, Uses & Tests
- `research.html` — Point of View, Assumptions & Limitations
- `contact.html` — Author & Research Contact
- `style.css` / `app.js` — shared presentation and theme logic

Theme modes: **Auto / Light / Dark**, with Auto as the default.

## GitHub Pages
In **Settings → Pages**, select **Deploy from a branch**, choose **main**, and choose **/(root)**. The entry point is `index.html`.

The site is designed as a research presentation of HMGQM Theory v3.1 and keeps the scientific distinction between established physics, model assumptions, and HMGQM hypotheses explicit.
